ASSETS DE MORADA

1) LOGO
   Nombre exacto: logo-morada.png
   Ruta: assets/logo-morada.png

   Recomendado:
   - PNG con fondo transparente.
   - Ideal: aproximadamente 1200 x 800 px.
   - Puede ser más grande; el CSS lo escala automáticamente.
   - Conviene que el archivo contenga el logo completo:
     símbolo + MORADA + “Mantenimiento Residencial”.

2) FONDO HERO
   Por ahora el CSS usa una fotografía remota de Unsplash.
   Si después quieres usar tu propia foto, guárdala como:
   assets/hero-morada.jpg

   y en styles.css cambia la URL de Unsplash por:
   url("./assets/hero-morada.jpg")

3) INSTAGRAM
   En index.html reemplaza:
   https://www.instagram.com/
   por el enlace real del Instagram de MORADA.
